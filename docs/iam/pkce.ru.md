# PKCE в Core IAM

Core IAM поддерживает необязательный PKCE с `code_challenge_method=S256`
в потоке авторизации OIDC authorization code. Существующие клиенты могут
продолжать авторизацию и обмен кодов без PKCE. Поддержка объявляется
в поле `code_challenge_methods_supported` документа OIDC discovery.

## Действия клиента

1. Для каждой попытки входа генерируйте криптографически случайный
   `code_verifier`: строку длиной 43–128 символов из набора
   `A-Z`, `a-z`, `0-9`, `-`, `.`, `_`, `~`.
2. Вычислите `code_challenge = BASE64URL(SHA256(ASCII(code_verifier)))`
   без символов дополнения Base64. Сохраните verifier локально до обмена кода.
3. Передайте `code_challenge` и `code_challenge_method=S256` вместе
   с существующими параметрами авторизации в
   `/v1/iam/idp/{idp_uuid}/actions/authorize/invoke`.
4. Проверьте возвращённый `state`, затем передайте `code_verifier` вместе
   с `grant_type=authorization_code`, `code` и `redirect_uri` в
   `/v1/iam/clients/{client_uuid}/actions/get_token/invoke`.

Поддерживается только `S256`. При передаче challenge метод нужно указать явно:
значение `plain` и отсутствие метода отклоняются. Challenge должен содержать
ровно 43 символа Base64url без дополнения.

Для кодов, выданных с PKCE, перед выдачей токена IAM проверяет verifier,
клиента, точное совпадение redirect URI, срок действия кода и завершение
авторизации. При ошибке обмена возвращается `invalid_grant`, код не погашается.
Успешный обмен погашает код в одной транзакции с блокировкой строки БД.
Передача verifier для кода, выданного без challenge, отклоняется.

PKCE остаётся необязательным: в этой реализации нет настройки обязательного
PKCE для отдельных клиентов. Существующее поведение кодов, выданных без PKCE,
сохраняется. PKCE не заменяет аутентификацию клиента и проверку `state`.

## Развёртывание

Перед запуском обновлённого API примените миграцию
`0011-iam-pkce-3e8a1472.py`. Она добавляет два столбца, допускающих `NULL`;
существующие записи авторизации остаются пригодными для использования.

Описание протокола: [RFC 7636](https://www.rfc-editor.org/rfc/rfc7636).
