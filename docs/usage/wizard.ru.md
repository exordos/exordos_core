## Обзор

Мастер `exordos init` собирает всё необходимое для платформизации проекта через короткую серию интерактивных вопросов. Вопросы адаптируются в зависимости от ваших ответов, поэтому знать все опции CLI заранее не нужно.

Общее описание команды см. в [`exordos init`](../app-developer-guide/init.ru.md).

## Шаги

1. **Выбор типа проекта** — Generic, Python или Node.js (20/22/24).
2. **Настройка манифеста** — описание, репозиторий элементов (куда публикуются собранные образы) и настройки PostgreSQL, если проекту нужна база данных.
3. **Настройка CI/CD** — GitLab CI, GitHub Actions, оба варианта или ни одного. На данный момент файлы генерирует только GitLab CI; варианты с GitHub принимаются, но конфигурация не создаётся.

### Вопросы для Python

- Менеджер пакетов: `uv` или `pip`.
- Список systemd-сервисов, которыми управляет проект (через запятую).

### Вопросы для Node.js

- Нужно ли устанавливать Redis, Nginx и PM2.
- Список устанавливаемых пакетов.
- Пользователь, от имени которого будет запускаться приложение.

После ответа на все вопросы мастер генерирует манифест и конфигурацию CI/CD, а затем выводит сводку по всему созданному.
